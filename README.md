# legacists

Java・JSP・XHTML・JavaScriptなどのコード間の関連を可視化し、選択したソースをテキストにまとめて開発環境のAIへ渡す、Windows 11向けデスクトップアプリを開発するプロジェクトです。

初期版の実装と開発時確認は[Issue #3](https://github.com/kz-oshiro/legacists/issues/3)で管理しています。Rust解析CoreとVue/Tauriの開発版、試験・ビルドの入口があります。全体検証・性能確認は後続工程で扱い、配布版はまだ公開していません。実EXEの操作を通す結合試験は確認が完了していません。

## 開発版の機能

- プロジェクトのフォルダを選び、Java・JSP・XHTML・JavaScriptとXML・プロパティファイルの参照関係を静的に解析する。
- プロジェクト全体の概要と、選択したファイルに関連するファイルをグラフで調べる。
- グラフとソース表示を連動させ、関係の根拠となる位置へ移動する。
- 必要なファイルを手動選択し、ソース全文・相対パス・関係情報をUTF-8のTXTへ出力する。800KBを基準に分割できる。
- UTF-8・SJIS系の文字コードをファイルごとに判定し、必要に応じて手動指定する。
- ソースの変更は手動再解析で反映し、出力前にも変更を確認する。
- 解析エラー時に、発生箇所・影響・確認項目・対処手順が分かる、人間向けのエラーレポートを表示・保存する。

開発版の完了判定と既知の未完了点はIssue #3で管理します。初期版の対応範囲と受入条件は[要件定義書](docs/requirements.md)、実現方法と採用技術は[設計書](docs/design.md)で管理します。

## 利用環境とデータの扱い

対応はWindows 11のx64のみで、ARM64は対象外です。GitHub ReleaseのZIPを展開すると実行EXE一つだけになり、EXE単独で移動できる構成でビルドします。既存WebView2を利用し、追加インストール・管理者権限・起動時ダウンロードは要求しません。開発版は既存WebView2で起動を確認しています。OSダイアログを含む操作全体の確認は未完了です。

解析は端末内で行い、解析対象のコードを実行・変更しません。AIサービスへ直接送信せず、利用者が内容を確認してTXTを保存する方式です。

初期版の入力文字コードはUTF-8・SJIS系（CP932を含む）のみとし、ほかの文字コードは追加しません。出力はUTF-8です。

選択状態・文字コード指定・除外設定などの設定は、ユーザー用データ領域へ保存します。アプリ内で既定・現在の保存先の確認、保存先変更、保存データ削除を行います。ソース本文と解析結果は永続保存せず、データ削除で解析元ファイルや保存済みTXTを削除しません。

AIへ渡す調査TXTには、利用者が選んだソースをそのまま含めます。解析エラー時には、本ツールを改修するCodexへ実ソースを渡してデバッグできない前提で、作業者が自分の端末で何を確認・対処すればよいか分かるエラーレポートを設けます。レポートにはソースを添付せず、相対パス・クラス名・位置、確認・対処と追加調査の案内を含めます。エラーレポートとAI向けTXTは内容が異なります。保存前に用途と内容を確認してください。

## 操作の流れ

1. 開発版EXEを起動し、「フォルダを開く」でプロジェクトを選びます。EXE名とウィンドウタイトルで版を確認できます。
2. Explorerのフォルダを開閉し、名前・相対パスを検索してファイルを開きます。行にポインターを置くと相対パス全文を確認できます。「さらに表示」がある場合は未取得のファイルへ進めます。関連グラフの方向・種類・解決状態・深度を絞り、関係を選ぶとソースと根拠を表示します。グラフの拡大・縮小・全体表示・起点への復帰を画面上から操作でき、ドラッグで移動できます。概要グラフからグループ内のファイルを調べられます。
3. 出力するファイルをチェック欄で一件ずつ選びます。閲覧だけでは出力対象に加わりません。
4. 「プレビューを作成」で内容と各TXTの容量を確認し、「TXTを保存」で保存先を選びます。同名ファイルがある場合は別の保存先を選んでください。入力が変わっていた場合は再解析が必要です。
5. 文字コード・除外・Webルート・TXT上限は「設定」で変更します。解析条件を変えた後は再解析します。保存データの移行・削除は終了・再起動後に行います。

パネルをタブの×で閉じた場合は、上部の「表示」からパネル名を選ぶと再表示できます。「すべてのパネルを表示」でまとめて戻せます。表示中のものを選ぶとそのタブへ切り替わります。解析結果・検索条件・出力対象・プレビューを保持するため、再起動や再解析は不要です。

設定の既定保存先は`%LOCALAPPDATA%\legacists\data`、保存先の案内は`%LOCALAPPDATA%\legacists\bootstrap.json`です。既定・現在・案内のパスを設定画面に表示します。

解析は静的な直接参照を対象とします。外部依存、動的な参照、曖昧な参照を確定扱いにしません。グラフは表示量を制限し、省略と総数を表示します。ソースとプレビューはページ単位で表示しますが、TXTには選択した復号済みソースの全文を出力します。復号不能なファイルを選択した場合は出力を止めます。

開発環境の準備と実行コマンドは[開発手順](docs/development.md#環境と実行入口)を参照してください。
