# legacists

Java・JSP・XHTML・JavaScriptなどのコード間の関連を可視化し、選択したソースをテキストにまとめて開発環境のAIへ渡す、Windows 11向けデスクトップアプリを開発するプロジェクトです。

初期版の要件定義は確定しました。設計は案の段階で、利用できるアプリや配布EXEはまだありません。

## 目指す機能

- プロジェクトのフォルダを選び、Java・JSP・XHTML・JavaScriptとXML・プロパティファイルの参照関係を静的に解析する。
- プロジェクト全体の概要と、選択したファイルに関連するファイルをグラフで調べる。
- グラフとソース表示を連動させ、関係の根拠となる位置へ移動する。
- 必要なファイルを手動選択し、ソース全文・相対パス・関係情報をUTF-8のTXTへ出力する。800KBを基準に分割できる。
- UTF-8・SJIS系の文字コードをファイルごとに判定し、必要に応じて手動指定する。
- ソースの変更は手動再解析で反映し、出力前にも変更を確認する。
- 解析エラー時に、発生箇所・影響・確認項目・対処手順が分かる、人間向けのエラーレポートを表示・保存する。

これは開発目標です。初期版の対応範囲と受入条件は[要件定義書](docs/requirements.md)、実現方法と技術候補は[設計書](docs/design.md)で管理します。

## 利用環境とデータの扱い

対応はWindows 11のx64のみで、ARM64は対象外です。GitHub ReleaseのZIPを展開すると実行EXE一つだけになり、EXE単独で移動しても使える配布を目指します。既存WebView2を利用し、追加インストール・管理者権限・起動時ダウンロードは要求しません。本アプリの起動確認は今後行います。

解析はオフラインで端末内に閉じ、解析対象のコードは実行・変更しない設計を前提とします。AIサービスへ直接送信せず、利用者が内容を確認してTXTを保存する方式です。

初期版の入力文字コードはUTF-8・SJIS系（CP932を含む）のみとし、ほかの文字コードは追加しません。出力はUTF-8です。

選択状態・文字コード指定・除外設定などの設定は、ユーザー用データ領域へ保存する方針です。アプリ内で既定・現在の保存先の確認、保存先変更、保存データ削除を行えるようにします。ソース本文と解析結果は永続保存せず、データ削除で解析元ファイルや保存済みTXTを削除しません。

AIへ渡す調査TXTには、利用者が選んだソースをそのまま含めます。解析エラー時には、本ツールを改修するCodexへ実ソースを渡してデバッグできない前提で、作業者が自分の端末で何を確認・対処すればよいか分かるエラーレポートを設けます。レポートにはソースを添付せず、相対パス・クラス名・位置、確認・対処と追加調査の案内を含めます。いずれも開発目標であり、実装後の具体的な手順と制限は、このREADMEに利用者向けに記載します。
